RUNG 000 [ADDED]
COMMENT
Receive source-controller facts before furnace programs run.
JSR(WH_ReceiveLinks,0);

RUNG 001 [ADDED]
COMMENT
More than one selected/stamped part is ambiguous; never pick the last scanned position.
GT(WH_Site.CandidateCount,1)MOVE(30,WH_Site.Fault);

RUNG 002 [ADDED]
COMMENT
The selected part requires one unambiguous 50 MN or 300 MN destination.
EQ(WH_Site.CandidateCount,1)NE(WH_Site.CandidatePress,50)NE(WH_Site.CandidatePress,300)MOVE(35,WH_Site.Fault);

RUNG 003 [ADDED]
COMMENT
Reject multiple accepted wash returns across the two-furnace scan.
GT(WH_Site.ReturnCount,1)MOVE(33,WH_Site.Fault);

RUNG 004 [ADDED]
COMMENT
Release the sole accepted return only after checking both furnace passes.
EQ(WH_Site.ReturnCount,1)EQ(WH_Site.Fault,0)MOVE(1,WH_Site.ReturnPending);

RUNG 005 [ADDED]
COMMENT
Begin the next accepted-return scan.
MOVE(0,WH_Site.ReturnCount);

RUNG 006 [ADDED]
COMMENT
Commit the candidate only after both furnace Pre dispatches have been scanned.
EQ(WH_Site.CandidateCount,1)EQ(WH_Site.Active,0)EQ(WH_Site.Fault,0)OTE(WH_BindCandidate);

RUNG 007 [ADDED]
COMMENT
Freeze the selected part/load identity before the legacy item can be moved or cleared.
XIC(WH_BindCandidate)[MOVE(WH_Site.CandidateIndex,WH_Site.Index),MOVE(WH_Site.CandidateFurnace,WH_Site.Furnace),MOVE(WH_Site.CandidatePress,WH_Site.Press),COP(WH_Site.CandidateItem,WH_Site.Item,1)];

RUNG 008 [ADDED]
COMMENT
Freeze the selected part/load identity before the legacy item can be moved or cleared.
XIC(WH_BindCandidate)[MOVE(1,WH_Site.Active),MOVE(0,WH_Site.Removed),MOVE(0,WH_Site.DecisionPending),MOVE(0,WH_Site.CyclePending)];

RUNG 009 [ADDED]
COMMENT
Freeze the selected part/load identity before the legacy item can be moved or cleared.
XIC(WH_BindCandidate)[MOVE(0,WH_Site.DecisionObserved),MOVE(WH_SelectedCDL,WH_Site.CdlId)];

RUNG 015 [ADDED]
COMMENT
A second CDL start while a part is still handled is an overrun.

COMMENT
